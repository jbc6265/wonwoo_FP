# 원우ENG 서열정보&소요자재 자동 취합 프로그램

## 실행 방법

`Wonwoo_Key_Column_Merge_Planner.cmd`를 더블클릭해서 실행합니다. CMD는 기존 Python GUI 파일을 실행하며 별도 프로그램 파일을 생성하지 않습니다.

## 목적

현대건설기계 HI-SRM에서 내려받은 월확정조립서열계획과 물류번호별 소요자재현황을 `생산번호 = 물류번호` 기준으로 병합합니다. 각 입력 파일의 전체 컬럼 목록에서 출력할 컬럼을 검색하고 복수 선택할 수 있습니다.

## 입력 파일

- 월확정조립서열계획 통합1라인
- 월확정조립서열계획 통합2라인
- 월확정조립서열계획 선진정공
- 월확정조립서열계획 초대형
- 물류번호별 소요자재현황

월확정 파일은 4개 중 1개 이상 선택하면 실행할 수 있고 자재소요현황은 필수입니다. 동일 파일을 두 입력 영역에 중복 선택할 수 없습니다.

## 병합 및 제외 규칙

- 월확정 Key: `생산번호`
- 자재소요 Key: `물류번호`
- 결과 Key 컬럼: `생산번호`
- `착수일/착수일자`는 결과에서 `착수일자`로 통합
- 모든 조립라인의 `DX~` 영업모델은 병합에서 제외하고 예외목록에 기록
- 선진정공의 `WX~` 영업모델은 원우ENG 대상이 아니므로 제외하고 예외목록에 기록
- 선진정공의 `HW~`, `R~` 모델은 정상 병합 대상
- 월확정 라인 간 생산번호가 중복되면 각 행은 유지하고 `월확정 Key 중복` 예외 기록
- 결과는 `착수일자 → 조립라인 → 생산번호` 순으로 정렬

## 중복 물류번호 처리

자재소요현황에 동일 물류번호가 여러 건이면 품명에 `카운터웨이트`, `COUNTER WEIGHT`, `COUNTERWEIGHT`가 포함된 자재를 우선 사용합니다. 후보가 여러 건이거나 후보가 없으면 예외목록에 기록합니다.

## 출력 컬럼

- 파일별 탭에서 컬럼 검색, 전체 선택, 전체 해제 및 복수 선택 지원
- 생산번호와 물류번호는 필수 Key로 자동 포함
- 월확정 파일끼리 같은 컬럼명은 하나의 출력 컬럼으로 통합
- 월확정과 자재 파일에 같은 컬럼명이 선택되면 `월확정_`, `자재_` 접두어로 구분
- 서식만 남은 후행 빈 컬럼은 선택 목록에서 제외

## 출력 파일

파일명은 `원우ENG_Key_Column_Merge_YYYYMMDD_HHMMSS.xlsx` 형식으로 생성됩니다.

- `병합결과`: 정상 병합 데이터와 조립라인 출처
- `예외목록`: 모델 제외, 미매칭, Key 누락·중복, 착수일 불일치, CWT 선택 결과
- `검증요약`: 입력별 건수, 선택 컬럼, 모델 제외 건수, 정상 병합 및 예외 건수
