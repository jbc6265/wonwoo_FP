# 원우ENG 4개 조립라인 서열정보&소요자재 자동 취합 프로그램 계획안

## Summary

- 통합1라인, 통합2라인, 선진정공, 초대형 월확정조립서열계획을 하나의 병합 흐름으로 처리한다.
- `월확정.생산번호 = 자재소요.물류번호`를 Key로 병합한다.
- 각 원본 파일의 전체 컬럼을 파일별 탭에서 복수 선택한다.
- 월확정 파일은 1개 이상, 자재소요현황은 필수로 한다.

## 병합 규칙

- 모든 라인의 `DX~` 모델은 `DX 제품 제외`로 기록하고 병합하지 않는다.
- 선진정공의 `WX~` 모델은 `WX 제품 제외`로 기록하고 병합하지 않는다.
- 자재 중복은 카운터웨이트 품명 우선 규칙으로 한 행을 선택한다.
- 동일 생산번호가 여러 월확정 행에 있으면 행은 모두 유지하고 중복 예외를 남긴다.
- 결과에는 `조립라인`을 기록하고 `착수일자`, `조립라인`, `생산번호` 순으로 정렬한다.

## UI 및 출력

- 월확정 4개 라인을 2×2 파일 선택 영역으로 표시하고 자재소요현황은 별도 필수 영역으로 표시한다.
- 컬럼 선택은 5개 파일별 탭, 검색, 전체 선택·해제를 제공한다.
- 결과 파일은 `병합결과`, `예외목록`, `검증요약` 3개 시트로 생성한다.
- 기존 CMD와 Python 파일명을 유지한다.

## 검증 기준

- 샘플 5개 파일의 실제 헤더 행과 컬럼 수를 인식한다.
- 선진정공 `WX~`와 전체 라인 `DX~`가 결과에서 제외되고 예외목록에 개별 기록된다.
- 결과의 Key 공란, 제외 모델 잔존, 수식 오류가 없어야 한다.
- 출력 시트의 필터, 고정 헤더, 컬럼 폭과 검증요약 건수를 확인한다.
