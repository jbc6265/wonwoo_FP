# 원우ENG CWT 생산계획 수립 프로그램

## 실행 방법

Windows에서는 `Wonwoo_CWT_Planner_Python.cmd`를 더블클릭해서 실행합니다.

Python GUI 버전은 월확정 통합1라인 또는 통합2라인 중 한 가지 파일만 있어도 실행할 수 있습니다. 단, 물류번호별 자재소요현황 파일은 필수입니다.

## 입력 파일

1. 월확정조립서열계획 통합1라인
2. 월확정조립서열계획 통합2라인
3. 물류번호별 자재소요현황

## 처리 기준

- 월확정 통합1라인은 전체 사용합니다.
- 월확정 통합2라인은 `영업모델`이 `HX~` 또는 `R~`인 현대 제품만 사용합니다.
- 통합2라인의 `DX~` 디벨론 제품은 생산계획에서 제외하고 `예외목록` 시트에 남깁니다.
- 물류번호별 자재소요현황은 `품명`에 `카운터웨이트`가 포함된 건만 사용합니다.
- 통합1라인 자재는 `물류번호 KPA10~` 또는 `KSA10~`로 판별합니다.
- 통합2라인 자재는 `물류번호 KPA20~` 또는 `KSA20~`로 판별합니다.
- 월확정 통합1라인만 선택하면 통합1라인 자재만 생산계획 대상이 되고, 통합2라인 자재는 예외목록에 남깁니다.
- 월확정 통합2라인만 선택하면 통합2라인 자재만 생산계획 대상이 되고, 통합1라인 자재는 예외목록에 남깁니다.
- 매칭 키는 `생산번호 = 물류번호`입니다.
- 엑셀 열 순서가 바뀌어도 헤더명 기준으로 필요한 컬럼을 찾습니다.

## 출력 파일

착수일 최소/최대 기준으로 파일명이 자동 생성됩니다.

예: `원우ENG_CWT_생산계획_20260713-20260720.xlsx`

동일한 파일명이 이미 있으면 기존 파일을 덮어쓰지 않고 번호를 붙여 저장합니다.

예:

- `원우ENG_CWT_생산계획_20260713-20260720.xlsx`
- `원우ENG_CWT_생산계획_20260713-20260720_001.xlsx`
- `원우ENG_CWT_생산계획_20260713-20260720_002.xlsx`
