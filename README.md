# 원우ENG CWT 생산계획 수립 프로그램

## 실행 방법

### HTML 단독 실행

`index.html`을 브라우저로 열고 아래 3개 파일을 각각 업로드합니다.

1. 월확정조립서열계획 통합1라인
2. 월확정조립서열계획 통합2라인
3. 물류번호별 자재소요현황

### Python GUI 실행

Python 3 설치 후 아래 명령을 실행합니다.

```bat
pip install -r requirements.txt
python Wonwoo_CWT_Planner_Python.py
```

Windows에서는 `Wonwoo_CWT_Planner_Python.cmd`를 더블클릭해도 실행할 수 있습니다.

Python GUI 버전은 월확정 통합1라인 또는 통합2라인 중 한 가지 파일만 있어도 실행할 수 있습니다. 단, 물류번호별 자재소요현황 파일은 필수입니다.

### EXE 실행

Windows 환경에서 PyInstaller로 빌드한 뒤 `dist` 폴더의 실행 파일을 배포합니다.

```bat
build_windows_exe.cmd
```

## 처리 기준

- 월확정 통합1라인은 전체 사용합니다.
- 월확정 통합2라인은 `영업모델`이 `HX~` 또는 `R~`인 현대 제품만 사용합니다.
- 통합2라인의 `DX~` 디벨론 제품은 생산계획에서 제외하고 `예외목록` 시트에 남깁니다.
- 월확정 통합1라인만 선택하면 `KPA10~` 자재만 생산계획 대상이 되고, `KPA20~` 자재는 예외목록에 남깁니다.
- 월확정 통합2라인만 선택하면 `KPA20~` 자재만 생산계획 대상이 되고, `KPA10~` 자재는 예외목록에 남깁니다.
- 물류번호별 자재소요현황은 `품명`에 `카운터웨이트`가 포함된 건만 사용합니다.
- 통합1라인 자재는 `물류번호 KPA10~`, 통합2라인 자재는 `물류번호 KPA20~`로 판별합니다.
- 매칭 키는 `생산번호 = 물류번호`입니다.
- 정상건은 `생산계획` 시트, 예외건은 `예외목록` 시트, 집계는 `검증요약` 시트에 출력합니다.

## 출력 파일

착수일 최소/최대 기준으로 파일명이 자동 생성됩니다.

예: `원우ENG_CWT_생산계획_20260713-20260720.xlsx`
